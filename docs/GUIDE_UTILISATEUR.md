# Guide utilisateur

## Connexion

Ouvrir l’application, saisir email et mot de passe. En cas d’oubli, contacter uniquement l’administrateur.

## Dashboard

Le dashboard affiche :

- total des entrées ;
- total des sorties ;
- solde automatique ;
- graphiques mensuels ;
- activités récentes.

## Entrées / sorties

Saisir le libellé, le montant, la date, la catégorie et la référence. Le solde est calculé automatiquement par la formule :

```text
TOTAL = ENTREES - SORTIES
```

## Fidèles

Créer une fiche avec matricule, photo, téléphone, dates de baptême et communion. Une carte membre avec QR code peut être imprimée.

## Obligations

Associer une obligation à un fidèle et à une période. Le statut est calculé selon le montant payé.

## Rapports

Filtrer par période pour produire un rapport journalier, mensuel, annuel ou personnalisé. Export PDF et Excel disponibles.
