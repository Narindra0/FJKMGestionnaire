# Cas d’utilisation

## ADMIN

- Se connecter avec sécurité renforcée.
- Créer et gérer les comptes utilisateurs.
- Consulter tous les dashboards.
- Gérer les entrées, sorties, fidèles, obligations, communion.
- Exporter PDF/Excel.
- Consulter les logs et historiques.

## USER

- Saisir les entrées financières.
- Saisir les sorties financières.
- Créer les fiches fidèles.
- Gérer obligations et paiements communion.
- Consulter dashboards et rapports.

## VISITEUR

- Consulter les statistiques.
- Visualiser les graphiques.
- Accès lecture seule, sans modification.
